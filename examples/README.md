# Example configurations

Copy one to `~/.config/manimon/config.toml` and edit.

- `config.toml` — every option, commented. Generated by `manimon config --sample`.

With no config file at all maniMon still runs: the machine sections (CPU,
memory, GPU, disks, network, sensors, store) need no configuration, and the
job, repo, backup and campaign sections stay hidden until you point them at
something.
